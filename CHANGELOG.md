# Changelog

## 1.0.0

First release.

- Reporting-year clock in the bottom bar (next to Earnings).
- Event calendar: all vehicles and multiple units that appeared in or left the store since the game started and will do so later, by year, with game time until each future year; opens at the current year.
- Columns: vehicle type, picture, model, status, engine, cargo specialization; filters by type, engine and specialization.
- Milestones: construction cost inflation, catenary.
- Vehicle details window as in the vehicle store, next to the list.
- UI and mod description in all 13 game languages.
